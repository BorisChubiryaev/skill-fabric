# OCR → Word (офлайн, профессиональное распознавание)

Переносимый навык для кодинг-агента (GigaCode Desktop, Claude Code и совместимых):
извлекает текст из изображений, сканов PDF и фотографий документов и собирает
редактируемый файл **Word (`.docx`)**. Работает **локально** на движке Tesseract —
без сети, API-ключей и загрузки документов куда-либо, что важно для чувствительных
бумаг. Языки по умолчанию — русский + английский.

## Что делает и чего не делает

Ключевая идея — не просто «прогнать OCR», а не выдать мусор за текст: инструмент
считает уверенность распознавания по страницам, помечает сомнительные места
красным в DOCX и честно предупреждает о плохом входе.

- **Хорошо**: чистые сканы и цифровые изображения печатного текста (рус/англ);
  фото с телефона после автоматической предобработки (выравнивание перекоса,
  апскейл, шумоподавление); многостраничные PDF.
- **Не для этого движка**: рукописный текст (нужна vision-модель), сложные
  таблицы (переносится текст, но не структура), точное форматирование оригинала.

Подробности — в `references/ocr-notes.md`.

## Требования

- бинарь `tesseract` + языковые пакеты `rus`, `eng`;
- Python 3.11+ и пакеты: `pytesseract pillow numpy opencv-python-headless pymupdf
  python-docx`;
- рендерер DOCX (Word/LibreOffice) — необязательно, только чтобы открыть результат.

Установка зависит от машины (`apt` на Linux, `brew install tesseract
tesseract-lang` на macOS, а **без sudo/Homebrew** — Miniforge + conda-forge +
`uv run`). Полные рецепты, включая обход блокировки `curl`, — в
`references/install.md`. Команда `check` подскажет, чего не хватает; скрипт сам
находит бинарь в conda/miniforge/brew или принимает путь через `--tesseract-cmd`.

Сеть при работе и платные API не нужны (сеть нужна один раз — только на установку).

## Установка из ZIP

```bash
unzip ocr-to-word.zip -d ~/.agents/skills
```

Появится `~/.agents/skills/ocr-to-word/` с `SKILL.md`. Вместо `.agents/skills`
используйте каталог навыков вашего агента (например, `~/.gigacode/skills/`).
Перезапустите сессию агента, чтобы он перечитал список навыков.

## Пример вызова

```text
$ocr-to-word Распознай текст с фото договора /путь/photo.jpg и собери
редактируемый Word (русский+английский). Результат и отчёт положи в /путь/out/.
```

Ожидаемые файлы:

- `photo.docx` — редактируемый текст в Word (ненадёжные места помечены красным);
- `photo_ocr_report.md` — уверенность по страницам и что перепроверить.

## Ручная проверка инструмента

```bash
python3 scripts/ocr_to_word.py check --lang rus+eng
python3 scripts/ocr_to_word.py ocr input.png --out out.docx --report out.md
python3 scripts/ocr_to_word.py ocr scan.pdf --out out.docx --json words.json --preprocess auto
python3 -m unittest scripts/test_ocr_to_word.py -v
```

## Гарантии и ограничения

Инструмент не перезаписывает исходный файл, публикует DOCX через временный файл
(без полурезультата), считает уверенность и помечает ненадёжные фрагменты. Навык
не распознаёт рукопись, не воспроизводит структуру таблиц и точное форматирование
оригинала и не гарантирует корректность при низком качестве входа.
