# API драйвера sber_driver

Справочник по действиям сессии `s`. Все они логируются автоматически: строка в
`run.log`, событие в `events.jsonl`, при падении — скриншот и снимок DOM. Пиши
сценарий из этих вызовов, а не на «голом» Playwright.

Сценарий — файл с функцией `run(s)`. Ничего импортировать не нужно: раннер сам
создаёт сессию и передаёт её.

## Навигация и ожидание

| Вызов | Что делает |
|---|---|
| `s.goto(url, wait_until="load")` | Перейти по адресу |
| `s.wait_for(sel, state="visible")` | Дождаться элемента (`visible`/`attached`/`hidden`) |
| `s.wait_for_url("**/done")` | Дождаться нужного URL (glob) |
| `s.wait_ms(ms)` | Пауза (крайняя мера — лучше ждать элемент) |

## Ввод

| Вызов | Что делает |
|---|---|
| `s.click(sel)` | Клик |
| `s.fill(sel, text)` | Задать значение поля целиком |
| `s.type(sel, text, delay_ms=0)` | Ввод посимвольно (для полей с реакцией на набор) |
| `s.press(sel, "Enter")` | Нажать клавишу |
| `s.select_option(sel, value)` | Выбрать пункт `<select>` |
| `s.check(sel)` | Поставить галочку |

Значения `fill`/`type` в лог по умолчанию **не пишутся** (только длина) — там
могут быть пароли и персональные данные. Показать их можно флагом `--show-values`
у команды `run`, но только по явной просьбе.

## Чтение данных

| Вызов | Возвращает |
|---|---|
| `s.text(sel)` | Текст одного элемента (строка) |
| `s.extract(sel, {"имя": подсел})` | Список словарей по строкам `sel`; без `fields` — `[{ "text": ... }]` |
| `s.eval_js("() => document.title")` | Результат произвольного JS |

Пример сбора таблицы:

```python
rows = s.extract("table.report tbody tr",
                 {"дата": "td.date", "сумма": "td.amount"})
# -> [{"дата": "...", "сумма": "..."}, ...]
```

## Скачивание

| Вызов | Возвращает |
|---|---|
| `s.download(sel, save_as="report.xlsx")` | Путь сохранённого файла |
| `s.download_via(trigger, save_as=...)` | То же, но триггер — функция (для нестандартных случаев) |

`download` сам кликает по элементу, дожидается файла (таймаут ≥ 60 с) и сохраняет
его в каталог загрузок прогона (или в `--download-dir`). В лог попадают имя и
размер файла. Не имитируй скачивание ручным кликом — потеряешь ожидание и учёт.

Если файл открывается во вкладке вместо загрузки (например, PDF), это видно по
таймауту download; тогда бери URL и качай его отдельно или ищи прямую ссылку.

## Диагностика внутри сценария

| Вызов | Что делает |
|---|---|
| `s.screenshot("метка")` | Ручной скриншот (для разведки/контрольных точек) |
| `with s.step("вход"): ...` | Пометить группу шагов в логе |

## Как обрабатываются ошибки

Любое действие при неудаче:

1. снимает скриншот и сохраняет снимок DOM на момент ошибки;
2. пишет событие с точным сообщением и временем;
3. поднимает `FlowError` — сценарий останавливается, дальнейшие шаги не идут.

Это намеренно: продолжать по сломанной странице бессмысленно, а лог уже содержит
всё для разбора. Если нужно продолжить несмотря на ошибку (редко), оберни шаг в
`try/except` в самом сценарии — но обычно правильнее починить селектор или
добавить ожидание.

## Таймауты

У каждого действия есть параметр `timeout_ms`, переопределяющий общий (по
умолчанию 15000 мс, меняется флагом `--timeout`). Поднимай его точечно для
заведомо медленных мест (тяжёлый отчёт, долгий редирект), а не глобально.
