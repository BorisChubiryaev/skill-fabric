# PDF → PPTX (редактируемая презентация)

Переносимый навык для кодинг-агента (GigaCode Desktop, Claude Code и совместимых):
конвертирует PDF в редактируемую презентацию PowerPoint (`.pptx`) — одна страница
PDF на слайд. Текст переносится как настоящие текстовые поля (правится в
PowerPoint), картинки — как изображения, графика сохраняется визуально. Исходный
PDF не изменяется.

## Насколько это качественно

PDF — формат фиксированной вёрстки, PPTX — редактируемая структура, поэтому
конвертация всегда балансирует между «точно как оригинал» и «удобно править».
Навык даёт три режима:

- **`hybrid`** (по умолчанию) — растровая подложка страницы **с удалённым
  текстом** (векторы и картинки сохранены) + настоящий редактируемый текст
  поверх. Выглядит почти как оригинал, текст полностью правится.
- **`text`** — текст и картинки как редактируемые объекты; векторная графика не
  переносится. Максимальная редактируемость, вид приблизительный.
- **`image`** — каждая страница как картинка. Точная копия, ничего не
  редактируется. Единственный честный вариант для сканов без OCR.

Хорошо конвертируются цифровые PDF (особенно бывшие слайды). Неизбежно теряются:
точные шрифты (подстановка сдвигает вёрстку), настоящие списки/таблицы, векторные
диаграммы. Сканы без предварительного OCR редактируемого текста не дают.
Подробности — в `references/conversion-notes.md`.

## Требования

- кодинг-агент с доступом к файлам и запуску команд;
- Python 3.11+;
- пакеты `pymupdf` и `python-pptx` (`pip install pymupdf python-pptx`);
- рендерер PPTX (PowerPoint/LibreOffice/Google Slides) — необязательно, только для
  визуальной проверки.

Сеть при работе и платные API не нужны.

## Установка из ZIP

```bash
unzip pdf-to-pptx.zip -d ~/.agents/skills
```

Должен появиться каталог `~/.agents/skills/pdf-to-pptx/` с `SKILL.md`. Вместо
`.agents/skills` используйте каталог навыков вашего агента (например,
`~/.gigacode/skills/` или `~/.codex/skills/`), если он настроен. Перезапустите
сессию агента, чтобы он перечитал список навыков.

## Пример вызова

```text
$pdf-to-pptx Сконвертируй /путь/презентация.pdf в редактируемую PPTX.
Режим hybrid, результат и отчёт положи в /путь/out/.
```

Ожидаемые файлы:

- `презентация.pptx` — редактируемая презентация;
- `презентация_report.md` — режим, статистика и перечень потерь качества.

## Ручная проверка инструмента

```bash
python3 scripts/pdf2pptx.py --help
python3 scripts/pdf2pptx.py analyze  input.pdf
python3 scripts/pdf2pptx.py convert  input.pdf --out out.pptx --report out.md --mode hybrid
python3 scripts/pdf2pptx.py verify   out.pptx
python3 -m unittest scripts/test_pdf2pptx.py -v
```

## Гарантии и ограничения

Инструмент не перезаписывает исходный PDF, публикует PPTX через временный файл
(без полурезультата), пишет отчёт с ограничениями и предоставляет независимую
команду `verify`. Навык не выполняет OCR, не распознаёт таблицы как таблицы и не
гарантирует пиксельную точность при подстановке шрифтов.
